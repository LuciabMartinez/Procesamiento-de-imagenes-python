# Machine Learning e Imágenes en Python

Ejercicios del curso *Machine Learning e Imágenes en Python* (Facultad de Ciencias Exactas, Físicas y Naturales, Universidad Nacional de Córdoba).

## Segmentación de flores: binarización y K-means
Segmentación de una imagen de flores (flores / hojas / fondo).

- **Binarización:** umbral elegido a mano a partir del histograma y comparado con el método de Otsu.
- **K-means:** clustering de los píxeles con las bandas RGB, visualización de los clusters en el espacio RGB y en la imagen, y comparación con la imagen binarizada.

**Herramientas:** Python, OpenCV, NumPy, pandas, scikit-learn, matplotlib
